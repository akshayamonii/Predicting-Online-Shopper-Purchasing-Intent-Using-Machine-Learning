# Predicting-Online-Shopper-Purchasing-Intent-Using-Machine-Learning

This project applies machine learning techniques to predict whether an online shopping session will lead to a purchase. Using the Online Shoppers Purchasing Intention Dataset, the model analyzes user behavior patterns—such as page interactions, session durations, exit rates, seasonal trends, and visitor types—to classify sessions as purchase or non-purchase.

This project was completed as part of a Machine Learning course and demonstrates a full ML workflow including data exploration, preprocessing, model training, evaluation, and interpretation.

Link to dataset: https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset
